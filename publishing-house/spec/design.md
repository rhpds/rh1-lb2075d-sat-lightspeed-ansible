# Red Hat Satellite: Compliance Scanning, Image Mode, and Vulnerability Remediation

## Overview

This lab provides hands-on experience with Red Hat Satellite's capabilities for managing compliance, operating system image delivery, and vulnerability remediation across a fleet of Red Hat Enterprise Linux hosts. The environment arrives pre-provisioned with a Satellite server and two RHEL hosts, letting participants focus immediately on Satellite workflows rather than installation. Participants will configure and run compliance scans, inspect scan results, explore image mode for host lifecycle management, and detect and remediate vulnerabilities using Satellite's built-in tooling.

## Target Audience

- **Role:** Linux system administrators and infrastructure engineers responsible for managing and securing RHEL fleets
- **Experience level:** Intermediate
- **What they already know:** Basic Red Hat Enterprise Linux administration, familiarity with web-based management interfaces, and an understanding of general patch and compliance concepts
- **What they don't know:** How to use Red Hat Satellite to run compliance scans against policy frameworks, how to build and deploy image mode RHEL images through Satellite, and how to use Satellite's vulnerability management features to detect and remediate CVEs at scale

## Prerequisites

- Familiarity with basic Linux command-line operations (navigating the filesystem, running commands as root)
- General awareness of patch management and security compliance concepts
- No prior Red Hat Satellite experience required
- Prerequisites cannot be automatically validated by the lab environment; participants are expected to self-assess

## Learning Objectives

1. Configure a compliance scanning policy in Red Hat Satellite and assign it to managed RHEL hosts
2. Monitor compliance scan results and interpret findings across the managed host inventory
3. Deploy a RHEL image mode build through Red Hat Satellite to a managed host
4. Analyze vulnerability reports generated by Red Hat Satellite and remediate identified CVEs on managed hosts

## Environment

**Learner view:** When the lab starts, a Red Hat Satellite server is fully installed and configured with content synchronized. Two RHEL hosts — rhel1.lab and rhel2.lab — are registered to Satellite and visible in the host inventory. Participants access Satellite through a dedicated Web UI tab and interact with the RHEL hosts via terminal tabs (SSH as root via Wetty). No additional provisioning is required before beginning the lab exercises.

**Automation needed:** Yes

The setup automation provisions and configures the following before lab start: Satellite server installation and initial configuration, content synchronization (RHEL repositories), registration of rhel1.lab and rhel2.lab as managed hosts, and baseline Satellite settings needed for compliance and vulnerability scanning.

## Assessment Strategy (Optional)

This is a Zero-Touch Guided lab using Nookbag. Each module includes a validate step that checks the expected state of the Satellite server and managed hosts:

- **Module 2 (Compliance Scanning):** Validation confirms a compliance policy has been created and a scan has been run against at least one managed host, with results visible in Satellite.
- **Module 3 (Image Mode):** Validation confirms an image mode build has been deployed and the target host is booted into the new image.
- **Module 4 (Vulnerability Remediation):** Validation confirms that identified CVEs have been remediated and the host's errata status in Satellite reflects the applied fixes.
